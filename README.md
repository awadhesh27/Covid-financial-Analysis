# COVID-19 Financial Impact Analysis

This project analyses corporate financial performance in Sweden and the Cayman Islands from 2017 to 2021.

## Key Insights
- Examined pre-pandemic, pandemic, and recovery periods
- Identified sector-level trends and structural differences
- Highlighted growth in finance sector during COVID period

## Tools Used
- R (tidyverse, ggplot2)
- Data cleaning & missingness analysis
- Exploratory data analysis
